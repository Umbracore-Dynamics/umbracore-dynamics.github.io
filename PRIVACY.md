# Privacy, Cookie, and Analytics Policy

**Effective date:** 2026-08-04

Umbracore Dynamics is committed to privacy by default and data minimization.

## Essential website storage

The website may use local browser storage for strictly necessary preferences, including:

- Language selection
- Light or dark theme
- Accessibility and motion preferences
- Privacy and analytics consent choices

These preferences support the operation of the website and are not used for advertising.

## Optional analytics

Optional analytics is disabled unless a visitor provides explicit consent.

Before consent:

- No analytics script is loaded.
- No analytics cookie is intentionally created by the website.
- No analytics event is transmitted.

When optional analytics is accepted and a valid analytics measurement identifier is configured, aggregate usage data may be collected. Advertising storage, advertising personalization, advertising user data, and Google Signals are disabled in the website configuration.

## Data excluded from analytics

The website does not intentionally send the following information to analytics:

- Names
- Email addresses
- Telephone numbers
- Organization names
- Contact-form content
- Consultation details
- Credentials
- Payment-card data
- Sensitive personal information
- Client-confidential information

## Contact channels

Direct communications through WhatsApp, Microsoft Outlook, LinkedIn, Medium, X, or other third-party services are also subject to the privacy practices and terms of those providers.

## Changing privacy choices

Visitors can reopen the **Privacy settings** control in the website footer at any time. A new selection replaces the previous analytics preference stored in the browser.

Clearing browser storage may reset the website's saved preference and cause the consent banner to appear again.

## Current analytics configuration

The public website contains a placeholder analytics measurement identifier. Optional analytics will not load until a valid identifier is configured and the visitor has consented.

## Security and retention

The public website does not currently operate a production contact-form backend or database. Contact information is therefore not stored by the website itself.

Any future backend must implement data minimization, access control, encryption, retention limits, deletion procedures, incident response, and applicable data-subject rights.
